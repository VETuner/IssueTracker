# VETuner Issue Tracker

Public issue tracker for [vetuner.co.uk](https://vetuner.co.uk).

This is an intake point. Issues needing engineering work are moved to the
development tracker and closed here with a link.

## Rather use the app?

If VETuner starts, use **Report Bug** inside it. That attaches your INI,
diagnostics, console log and a screenshot automatically, and it arrives
privately.

Use this tracker if you want a public discussion, need to attach files
yourself, or the app will not start.

## What to include

The firmware signature, if you know it — `speeduino 202501`, `MS3 Format
0601.16`. Reports without one often cannot be reproduced.

Also useful: steps, how you connect (USB on desktop, USB on Android, or
Bluetooth), the build hash from the footer, browser and OS, and a screenshot of
the whole window.

## Attach, do not paste

Attach your MSQ or INI as a file. Remove anything you would not want public —
tunes can contain vehicle details and location names. Never paste passwords or
API keys.

## Responses

Small project. A reply may take a while, a fix longer. Clear reports get looked
at first.
